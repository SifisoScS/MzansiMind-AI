# MzanziMind AI

> **Grow the Mind. Build the Nation. Prosper Together.**

![MzanziMind AI mission and vision: South Africans learning together, building skills, growing careers, and creating opportunity with AI mentorship](branding/MzanziMind_AI_Vision_Mission.png)

MzanziMind AI is a blueprint for an AI-native learning and empowerment platform designed to help South Africans build knowledge, skills, financial understanding, careers, and businesses.

## Vision

To build Africa's first AI-native learning and empowerment platform that transforms millions of people into highly skilled, financially intelligent, innovative citizens.

## Mission

Provide every South African with a personalized AI mentor capable of teaching, coaching, guiding and empowering them.

## What the platform is designed to support

The product blueprint lists these planned capabilities:

- AI Learning Coach
- AI Career Coach
- AI Financial Coach
- AI Business Mentor
- AI Innovation Lab
- AI Community Builder
- AI Research Assistant
- AI Language Tutor

These are planned product capabilities, not implemented features.

## Core pillars

- Education
- Financial literacy
- Entrepreneurship
- Career development
- Leadership
- Innovation

## Intended audiences

The blueprint identifies students, graduates, entrepreneurs, teachers, parents, workers, professionals, rural communities, job seekers, and government programs as intended audiences.

## Architecture and intended technology

The following is the blueprint's intended direction, not a description of deployed services.

| Area | Blueprint components |
| --- | --- |
| Experience | Web app, mobile app, admin console; Next.js, React, TypeScript |
| Backend and APIs | FastAPI, Python, GraphQL, REST APIs |
| AI and knowledge | GPT, open-source LLMs, RAG, fine-tuned models, multi-agent collaboration, vector search, knowledge graph |
| Data | PostgreSQL, Redis, Azure Blob Storage |
| Cloud and operations | Azure, Azure Kubernetes Service, Azure OpenAI, Azure AI Search, Azure Monitor, Docker, Kubernetes |
| Security | OAuth2, JWT, RBAC, Zero Trust, encryption, identity management |

## Project status

This repository currently contains the project blueprint, documentation, and organizational placeholders. It does **not** contain a functional application, operational AI agents, APIs, or deployed services. Items without a blueprint definition remain marked as pending rather than being inferred or implemented.
